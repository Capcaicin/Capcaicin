# Capcaicin

I build practical software systems that combine automation, AI tooling, infrastructure, and product-focused interfaces. My work is strongest where prototypes need to become usable systems: routing services, local-first AI workflows, media automation, developer tooling, and small full-stack applications.

## Focus Areas

- AI-assisted applications, local LLM routing, and retrieval workflows
- Backend services with Python, FastAPI, Node.js, and Express
- Automation and operations tooling with Docker, PowerShell, and CI/CD
- Frontend/product interfaces for dashboards, utilities, and media apps
- Security-minded development practices, secrets handling, and testable infrastructure

## How I Work

- I prefer clear, runnable projects with documented setup steps.
- I keep secrets out of source control and favor environment variables, keyrings, and sample config files.
- I write project documentation for future maintainers, not just for the first run.
- I value small, verifiable improvements over fragile one-off scripts.

## Current Direction

I am sharpening this profile around production-minded AI tooling, automation, and infrastructure projects. Public repositories are being cleaned up to emphasize readable documentation, safe defaults, and clear project purpose.
